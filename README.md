## 🐞 Bugs
➤ The first step to reporting a bug is to find out if it's a bug or a mod conflict, to determine this:
- Test without other mods loaded, just this mod + it's requirements, if the issue persists it is probably a bug.
- If the issue only happens with other mods loaded, it is a mod conflict - remove mods from your mod list until the issue disappears and take note of the conflicting mod.

➤ Next, be specific in describing the conditions and actions needed to demonstrate the issue.
- You have to provide accurate instructions to recreate the issue, if we can't reproduce it on our own system, we can't fix it.
- Describe the context in which the issue happens. Is it only in multiplayer? Only in a specific mission? How are you testing?
- Clearly describe the steps to create the issue, for example: Load the game, open the virtual arsenal and try tapping the shoulder of a unit using the keybind CTRL + T.

➤ Finally, please use the provided form and correct thread for the mod on our [Discord](steam://openurl_external/https://steamcommunity.com/linkfilter/?u=https%3A%2F%2Fdiscord.gg%2F8h44QVqyxX).

```
Type of Issue:
Bug (Issue only present when loading just this mod and its requirements) / Mod Conflict (Issue only present when I load other mods) [Select One]

Conflicting Mod: (If applicable)
Zeus Enhanced [Name the mod that causes this mod to not function properly]

Description:
The CBA settings are not visible in the 3DEN editor. [Brief description of the issue]

Steps to Recreate:
Load into ArmA with @cba, @ace, @thisMod and Zeus Enhanced, open the 3DEN editor, open the CBA settings menu. [Detailed and repeatable steps to replicate the issue]
```
